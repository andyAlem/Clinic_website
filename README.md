# Clinic Website

Проект представляет собой веб-приложение на Django для управления клиникой. Используется база данных PostgreSQL, все сервисы запускаются в Docker-контейнерах для удобства разработки и деплоя.

---

## Описание проекта

Веб-приложение предоставляет функционал для управления информацией о клинике, пользователях и другой связанной информацией.  
Проект использует:

- **Django 5.2.4** — основной фреймворк для разработки веб-приложения на Python  
- **PostgreSQL 16** — реляционная база данных для хранения данных  
- **Docker и Docker Compose** — для контейнеризации и удобного запуска сервисов  

---

## Структура проекта

- `/clinic_website` — основной код приложения  
- `/config` — конфигурация Django  
- `manage.py` — точка входа для управления проектом  
- `Dockerfile` — инструкция по созданию образа приложения  
- `docker-compose.yml` — описание сервисов для запуска базы данных и веб-приложения  
- `requirements.txt` — зависимости Python

## Инструкция по запуску

1. Клонируйте репозиторий:
git clone https://github.com/andyAlem/Clinic_website.git
cd Clinic_website

2. Постройте образы и запустите контейнеры:

docker compose up --build

3. Перейдите в браузере на адрес http://localhost:8000/

4. При необходимости выполните миграции базы данных:
docker compose run web python manage.py migrate

5. Остановка контейнеров:
docker compose down

# Дополнительно

    Контейнер с базой данных PostgreSQL запускается автоматически и хранит данные в volume, чтобы избежать потери данных при перезапуске.

    Для разработки можно подключаться в контейнер с веб-приложением командой docker compose run web bash и запускать команды Django вручную.

    Убедитесь, что в настройках Django (config/settings.py) правильно указаны параметры подключения к базе данных, соответствующие сервису db в Docker Compose.
